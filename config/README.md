# 配置与固件

本目录存放 PX4 飞控的参数备份与固件。

## 文件清单

| 文件 | 说明 |
|---|---|
| `px4_params_1.15.params` | **PX4 1.15 参数备份**（实际比赛使用版本） |
| `px4_params_1.13.params` | PX4 1.13 参数备份（历史版本） |
| `px4_params_1.12.3.params` | PX4 1.12.3 参数备份（最早版本） |
| `px4_fmu-v5_default-1.15.4.px4` | PX4 1.15.4 固件（Pixhawk 4 / FMU-v5 目标） |

> 三份参数文件反映了固件的**迭代过程**：1.12.3 → 1.13 → 1.15。
> 比赛最终使用 **PX4 1.15**（与 `reports/` 技术报告中的描述一致）。

---

## 关于参数文件

PX4 的 `.params` 文件是**纯文本的键值对**，记录了飞控的全部可调参数：

```
MAV_1_CONFIG    102     # TELEM1 端口用途（MAVLink）
MAV_1_BAUD      921600  # 波特率（与板载机通信）
SENS_EN_...     ...     # 传感器使能
EKF2_...        ...     # 扩展卡尔曼滤波参数
...
```

### 用途

| 场景 | 做法 |
|---|---|
| **备份** | 每次调参完成后导出，防止刷固件后丢失 |
| **恢复** | 换飞控 / 重刷固件后，导入参数文件一键恢复 |
| **对比** | 用 diff 对比不同版本，定位参数改动 |

```bash
# 对比两个版本的参数差异
diff px4_params_1.13.params px4_params_1.15.params
```

## 本项目关注的 PX4 关键配置

| 配置项 | 值 | 说明 |
|---|---|---|
| 板载机通信波特率 | **921600** | 与 Jetson/树莓派串口通信速率 |
| 飞行模式 | Offboard | 板载机接管控制 |
| 高度源 | 气压计（**已拆除**） | 拆除后高度靠 IMU 积分，会漂移 ← 详见 `docs/02` |

> **重要**：气压计被拆除是本项目的一个系统级隐患，导致高度漂移，进而引发里程计判定 Invalid 问题（详见排错笔记问题一）。
