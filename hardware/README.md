## 本项目实际使用的硬件

| 部件 | 型号 | 用途 |
|---|---|---|
| 飞控 | Pixhawk 4（PX4 1.15） | 姿态控制、动力输出 |
| 板载计算机 | Jetson Xavier NX 16GB | SLAM / 视觉 / 任务决策 |
| 激光雷达 | Livox Mid-360 | 室内定位与建图 |
| 双目相机 | Intel RealSense D455 | 二维码 / 图片靶 / 圆环识别 |
| 光流+激光测距 | 优象科技 T2 | **调研中**（作为高度源备选方案） |

> 关于高度源问题：由于飞控气压计被拆除，导致高度只能靠 IMU 积分而持续漂移（详见 `docs/02-FAST-LIO排错笔记.md` 问题一）。光流/激光测距模块是当时调研的替代高度源方案之一。
