# 报告插图

本目录是从技术报告 `.docx` 中导出的全部插图，**已按实际内容重命名**。

> **导出方式**：`.docx` 本质是 zip 包，图片位于 `word/media/`，直接从压缩包提取。
> 原始文件名是无意义的 `image1.jpeg` ~ `image18.png`，此处依据**文档上下文 + 逐张目视核对**重新命名。

## 一、重要说明：报告中的图号与实际图片并不完全对应

技术报告中声明了 **36 个图号**，但实际只有 **18 张图片** —— 近一半的图位是**只有标题、没有图片的空占位**。

此外，部分图片在文档中的**位置与图号存在错位**，例如：

| 报告中的图号 | 实际图片内容 | 说明 |
|---|---|---|
| 图 1-1「无人机整体重量测量照片」 | 轴距测量（卷尺） | **错位**：文档中第一个图位放的是轴距照片 |
| 图 1-2「无人机轴距测量照片」 | 桨叶保护圈（3D 打印件） | **错位** |

> 因此本目录采用**按实际内容命名**，而非沿用报告图号。下表的「报告中图号」列仅作参考。

## 四、场地坐标示意图详解（`16-场地坐标示意图.png`）

这张矢量图是本项目**最有价值的单张图** —— 它是整条任务链的"地图"，标注了全部道具坐标（单位 mm，原点在右下角）：

| 道具 | 坐标 | 说明 |
|---|---|---|
| 起飞点 | (1500, 3000) | 场地右侧中央 |
| 二维码 | (3300, 3000) | 起飞点正前方 1.8m |
| 障碍物 | (5800, 3000) | 场地中央（绕障目标） |
| 圆环移动区域 | (7500, 4600) 起 | 左上区域，2400 宽 |
| 图片靶 ×4 | (5100,4600) / (3300,4600) / (5100,1400) / (3300,1400) | 上下两排，各两个 |
| 特殊靶 | (7500, 2000) | 左侧 |
| 左降落点 | (1500, 1400) | 对应二维码 `left` |
| 右降落点 | (1500, 4600) | 对应二维码 `right` |

**场地尺寸**：9000 (X) × 6000 (Y)

> 对比 `src/mission_with_vision.py` 中的硬编码坐标可发现对应关系：
> - 二维码位置代码里写 `position_ref[0]=1.8, [1]=0` → 与示意图相对起飞点偏移一致
> - 图片靶代码里写 `[1.8, -1.6]`、`[3.6, -1.6]`、`[1.8, 1.6]`、`[3.6, 1.6]` → 对应四个图片靶
> - 降落点 `[0, 1.6]`（左）与 `[0, -1.6]`（右）→ 对应左右降落点
>
> **代码中的坐标是以起飞点为原点的相对坐标，示意图中是以场地右下角为原点的绝对坐标。**

## 附：如何自行导出 docx 中的图片

```python
import zipfile, os

docx = "无人机报告(2).docx"
z = zipfile.ZipFile(docx)
os.makedirs("images", exist_ok=True)

for name in z.namelist():
    if name.startswith("word/media/") and not name.endswith("/"):
        open(os.path.join("images", os.path.basename(name)), "wb").write(z.read(name))
```

> 也可以直接把 `.docx` 后缀改成 `.zip` 解压，图片在 `word/media/` 目录下。
